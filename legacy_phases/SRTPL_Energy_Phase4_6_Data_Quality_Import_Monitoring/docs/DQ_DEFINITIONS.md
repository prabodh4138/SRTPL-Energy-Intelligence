# Data Quality KPI Definitions

## Completeness
Received records / expected records × 100.

Expected records must come from configured asset/parameter schedules, not hard-coded numbers.

## Validation Pass Rate
Valid records / received records × 100.

## Duplicate Rate
Duplicate records / received records × 100.

## Exception Rate
Exception records / received records × 100.

## Manual Correction Rate
Manually corrected records / received records × 100.

## Audit Traceability
Records with complete source/import trace / received records × 100.

## Source Coverage
Reporting assets or expected asset-parameter combinations that supplied data / configured expected combinations × 100.

## Import Health
Tracks COMPLETED, PARTIAL, FAILED and blocked/duplicate import activity.

## Exception Ageing
Open exceptions grouped by age and severity.

NULL policy:
No-data is displayed as 'No data' and must never be represented as zero merely to make a KPI look complete.
