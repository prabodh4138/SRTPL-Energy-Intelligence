# Integration Rules

1. One source of truth per business concept.
2. No duplicate master tables for the same entity.
3. Original JUNO source remains immutable.
4. Raw and normalized data remain separate.
5. Validation occurs before KPI eligibility.
6. KPI formulas are versioned.
7. Master configuration is versioned/effective-dated.
8. Audit records are append-only.
9. Administrative writes require protected server-side operations.
10. No fake/demo values in production.
11. NULL remains distinct from zero.
12. TPWODL remains an extension point.
