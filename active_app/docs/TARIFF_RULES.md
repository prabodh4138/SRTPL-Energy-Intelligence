# Tariff Rules

Tariffs must be effective-date based.

Do not overwrite an old tariff when a new tariff becomes effective.

Example:
2026-04-01 → tariff version A
2027-04-01 → tariff version B

Historical reports must use the tariff applicable to the reporting date.

TPWODL bill reconciliation will later use this master rather than hard-coded rates.
