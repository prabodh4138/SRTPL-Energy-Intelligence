# Configuration Rules

1. Do not hard-code plaza relationships in Python.
2. Do not hard-code equipment IDs.
3. Do not hard-code threshold values in Streamlit.
4. Do not hard-code tariffs in KPI formulas.
5. Do not overwrite historical configurations.
6. Use effective dates/version numbers.
7. Configuration changes require Phase 4.8 change control.
8. Every applied configuration change must be audited.
9. Historical KPI results must retain the configuration/KPI version used.
10. Inactive master records remain available for historical traceability.
