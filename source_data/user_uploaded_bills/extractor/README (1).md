\# Energy Bill PDF to Excel



Upload electricity bill PDFs and download a clean Excel file.



\## Features

\- Extracts complete bill data

\- Correct Net Payable (Before \& After Rebate)

\- MD-KW / MD-KVA extraction

\- Mobile friendly

\- Fast processing



\## How to Run Locally

```bash

pip install -r requirements.txt

streamlit run app.py
